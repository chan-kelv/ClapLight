# D-03 Pairing flow — legacy devices

Walk the user through holding the power button and requesting a token (Panels, Shapes, Lines, Canvas, Elements).

## Acceptance criteria

- [ ] Wizard screen: device picked → "hold power button 5–7s" instruction with animation/timer
- [ ] After user confirms, app POSTs to `/api/v1/new` with 25s retry window (poll every 3s)
- [ ] On 200: token saved encrypted, device persisted, return to device list
- [ ] On timeout: clear error with "try again" + "use Essentials flow" options
- [ ] On any other error: show response code + body
