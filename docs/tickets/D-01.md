# D-01 mDNS discovery

Use `NsdManager` to discover Nanoleaf devices on the LAN.

## Acceptance criteria

- [ ] Service type `_nanoleafapi._tcp` resolved to (host, port, instance name)
- [ ] `MulticastLock` acquired during discovery, released after
- [ ] Discovery times out after 8s and reports devices found so far
- [ ] Results exposed as `Flow<List<DiscoveredDevice>>`
- [ ] Already-paired devices marked as such (matched by mDNS instance name or stored MAC if available)

## Technical notes

- Samsung One UI has historical mDNS reliability issues. Fall through to manual entry (D-02).
- Some devices broadcast firmware version in TXT records; capture if present.
