# S-02 Scene editor UI

Create/edit a scene by picking a target state per device.

## Acceptance criteria

- [ ] List of all paired devices, each with a "target" picker:
  - Off
  - Effect (dropdown from cached effects list, C-04)
  - Solid color (reuses C-03)
  - White temp
  - 4D mode (only if device is 4D-capable; see E-03)
- [ ] Brightness slider applies to all non-Off targets
- [ ] Scene name + icon selection
- [ ] Preview button (applies the scene without saving)
- [ ] Save / cancel

## Technical notes

- "Don't change" is a valid target option — meaning the scene leaves that device alone. Store as the absence of a `SceneTargetEntity` row for that device.
