# F-02 Networking layer (Retrofit + OkHttp)

Build the shared HTTP client and two Retrofit services (legacy + Essentials variants).

## Acceptance criteria

- [ ] Single `OkHttpClient` with 2s connect / 3s read timeouts
- [ ] Moshi configured with adapters for state, effects, layout, info DTOs
- [ ] `NanoleafApi` Retrofit interface covering: `getInfo`, `setState`, `getEffectsList`, `selectEffect`, `identify`, `writeEffect` (for emersion + extControl), `addUser`
- [ ] `BaseUrlInterceptor` rewriting per-call to `http://<host>:<port>/api/v1/<token>/` from device record
- [ ] Logging interceptor in debug builds only; token redacted

## Technical notes

- Use Retrofit's dynamic URL feature via `@Url` on a wrapper, or build a fresh Retrofit instance per device. The interceptor pattern is cleaner.
- DTOs for `setState` use sealed nested objects (e.g. `OnDto(value: Boolean)`). Don't use bare maps.
