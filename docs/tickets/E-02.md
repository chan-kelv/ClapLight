# E-02 Emersion mode switching

Read and set 1D/2D/3D/4D via the undocumented endpoint.

## Acceptance criteria

- [ ] `getEmersionMode(deviceId)` → `PUT /effects` with `{"write":{"command":"getScreenMirrorMode"}}` → returns enum
- [ ] `setEmersionMode(deviceId, mode)` → `PUT /effects` with `{"write":{"command":"activateScreenMirror","screenMirrorMode":<int>}}`
- [ ] Integer mapping table is **1D→6, 2D→2, 3D→3, 4D→5** (see API reference)
- [ ] Detect `effects.select == "*Emersion*"` as "screen mirroring active"
- [ ] Graceful 4xx handling — endpoint may break on firmware updates

## Technical notes

- Test on real 4D hardware before committing to this in scenes. If Nanoleaf changes the payload shape in a firmware update, the `aionanoleaf2` repo will be the leading indicator.
