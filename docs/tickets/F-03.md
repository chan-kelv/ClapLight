# F-03 Local network access permission (Android 16+)

Request and handle the new runtime permission for accessing local-network devices.

## Acceptance criteria

- [ ] Manifest declares the local-network permission (target SDK 36 attribute)
- [ ] Request at first launch with a rationale screen explaining why ("control your Nanoleaf lights on your Wi-Fi")
- [ ] Graceful degradation if denied: show error + link to settings
- [ ] `CHANGE_WIFI_MULTICAST_STATE` declared for mDNS
- [ ] `INTERNET` declared (still required)

## Technical notes

- The runtime local-network permission is new in Android 16. On older versions it's auto-granted.
- Test on Android 16 emulator AND on real hardware.
