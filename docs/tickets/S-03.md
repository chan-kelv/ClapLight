# S-03 Scene apply engine

The coroutine fan-out that makes a scene actually happen.

## Acceptance criteria

- [ ] `ApplySceneUseCase(sceneId)` queries targets, launches `async` per device, awaits all
- [ ] Per-target retry once on transient network failure
- [ ] Returns a result per device (`Success`, `OfflineSkipped`, `Failed(reason)`)
- [ ] Total wall-clock cap of 6s; remaining targets are marked timeout
- [ ] Logs per-device latency in debug builds for tuning

## Technical notes

- For targets needing both power-on and an effect select, send them as separate calls. Don't combine.
- For Emersion targets, route via E-02.
