# C-02 On/off + brightness

The simplest writes. Get these working before anything else.

- [ ] `setBrightness(value, durationSec?)` → `PUT /state` with `{"brightness":{"value":..., "duration":...}}`
- [ ] Brightness slider debounced (200ms) so dragging doesn't flood the device
- [ ] Both succeed against legacy and Essentials devices
