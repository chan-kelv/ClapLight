# H-02 Widget action handler

The Receiver that runs scene-apply when a widget button is tapped.

## Acceptance criteria

- [ ] `BroadcastReceiver` registered for widget action intents
- [ ] In `onReceive`: `goAsync()`, launch coroutine on `Dispatchers.IO`, call `ApplySceneUseCase`
- [ ] Hard cap at 8s before calling `finish()` to avoid ANR
- [ ] On failure, post a notification with the error (user is away from the app at this point)
- [ ] Widget refreshes its "last applied" highlight via `AppWidgetManager.updateAppWidget`
