# D-05 Token storage (encrypted)

Tokens never live in plaintext. Centralized in a `TokenStore`.

## Acceptance criteria

- [ ] Backed by `EncryptedSharedPreferences` keyed by device id
- [ ] `getToken(deviceId)`, `putToken(deviceId, token)`, `removeToken(deviceId)`
- [ ] Logs never include token values (verify with logging interceptor in F-02)
- [ ] Wiping app data clears all tokens (default behavior, but test)
