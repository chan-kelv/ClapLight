# H-01 Home screen widget

Grid of scene buttons on the home screen — the core "1-touch" surface.

## Acceptance criteria

- [ ] `AppWidgetProvider` with configurable size (2x2 up to 4x4)
- [ ] Configuration activity at add-time: user picks which scenes to expose
- [ ] RemoteViews grid of scene icons + names, max 8 per widget
- [ ] Tap fires `PendingIntent` → H-02
- [ ] Last-applied scene gets a subtle highlight

## Technical notes

- RemoteViews is limited — no Compose, no custom views. Use `ImageView` + `TextView` per cell.
- Glance is an alternative if you want a Compose-style API for widgets; worth evaluating but adds dependency surface.
