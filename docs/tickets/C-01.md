# C-01 Device detail screen

Single-device control surface. The heart of v1 UX.

## Acceptance criteria

- [ ] Power toggle, brightness slider, current effect name
- [ ] Tap effect name → bottom sheet with effects list (C-04)
- [ ] Color picker entry point (C-03)
- [ ] Identify button (D-07)
- [ ] Reachability indicator (green/red dot based on last successful call)

## Technical notes

- ViewModel holds `StateFlow<DeviceState>`; UI is purely reactive
- Writes are optimistic — show new state immediately, roll back on error
