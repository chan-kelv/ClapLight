# F-01 Project setup & build config

Create the Android Studio project with the agreed tech stack and verify a clean build on device.

## Acceptance criteria

- [ ] New Compose project, Kotlin 2.x, min SDK 26, target SDK 36
- [ ] Hilt, Room, Retrofit, OkHttp, Moshi, Coroutines, WorkManager wired in `build.gradle.kts`
- [ ] Signing config for debug keystore committed (sideload-friendly)
- [ ] App launches to an empty Compose screen on physical device
- [ ] Package: `com.kelvin.claplight` (or your preferred reverse-DNS)
