# P-01 Error handling & retry

Centralize error UX.

## Acceptance criteria

- [ ] Network errors categorized: `Offline`, `Timeout`, `Auth (401/403)`, `NotFound (404)`, `Server (5xx)`, `Unknown`
- [ ] Auth errors trigger a "re-pair" prompt
- [ ] Offline errors silent in widget context, surfaced inline in app
- [ ] WorkManager retry for widget actions with exponential backoff (max 3 tries)
